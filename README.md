# ⏱️ Stop-Watch

A simple, responsive, and user-friendly Stopwatch web application built using HTML, CSS, and JavaScript. This project allows users to accurately track time and manage lap records with easy-to-use controls.

## 🚀 Features

### Timer Controls

- ▶️ **Start** — Starts the stopwatch
- ⏸️ **Stop** — Stops the stopwatch
- 🔄 **Reset** — Resets the timer to zero
- 🏁 **Lap** — Records the current lap time

### Additional Features

- Accurate time tracking
- Lap time recording
- Clean and simple user interface
- Responsive design for different screen sizes
- Easy-to-use buttons and controls
- Dynamic timer updates using JavaScript

## 🛠️ Technologies Used

- **HTML5** — Creates the structure of the application
- **CSS3** — Provides styling and responsive design
- **JavaScript** — Handles timer functionality and user interactions
